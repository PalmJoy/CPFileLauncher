02 // Workflow

How it works

01

Tap Ctrl twice

Or use Alt / ⌥ + middle-click. Change the triggers in Settings.

02

Organize into ten groups

Edit text and group names in the Edit window. Switch groups with number keys 0–9.

03

Choose and paste

Press Enter or click to paste into your previous app. Hold Shift while choosing to copy only.

Board shortcuts

03 // Use cases

Ways to use text snippets

Add and edit snippets in the Edit window, then use a keyboard or mouse trigger to bring up text you use often.

01

Email greetings and replies

Save greetings, thank-you messages and scheduling replies as text snippets. Pick one from the board to paste into email or chat without typing it again.

02

Addresses, signatures and links

Keep your address, email signature and frequently shared URLs ready to paste. Snippets can contain multiple lines of text.

03

Separate work and personal text

Organize snippets into ten groups. Switch groups with number keys and use a–z shortcuts for the first 26 snippets in each group.

04 // Setup

First launch

  1. Extract the zip

    Keep the CPClipboard folder together, with uiohook.dll next to CPClipboard.exe.

  2. Launch the app

    Open CPClipboard.exe. Access Settings from the tray menu.

  3. Open the board

    Tap Ctrl twice and choose a snippet. Pasting into an elevated app is unavailable; the snippet is copied instead.

  1. Move to Applications

    Extract the zip and move CPClipboard.app to Applications before opening it.

  2. Allow the first launch

    This build is not notarized. Verify its source before allowing it in System Settings → Privacy & Security.

  3. Allow Accessibility

    Allow CPClipboard in System Settings → Privacy & Security → Accessibility. Until permission is granted, selecting a snippet only copies it.

  4. Open the board

    Tap Ctrl twice and choose a snippet.

Add your snippets

Open Edit… from the tray or menu bar, choose a group, and select Add. Text edits are saved automatically.

05 // Storage

Storage and clipboard

Snippets are stored on your computer. By default, your selected snippet stays on the clipboard after pasting for reuse with Ctrl+V / ⌘V. Restoring the previous clipboard is optional and off by default. Clipboard history, variables, macros and cloud sync are outside the app’s scope.
