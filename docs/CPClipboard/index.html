WORKFLOW / 01—03

How it works

01 / OPEN

Tap Ctrl twice

Or use Alt / ⌥ + middle-click. Change the triggers in Settings.

02 / CHOOSE

Organize into ten groups

Edit text and group names in Settings → Snippets. Switch groups with number keys 0–9.

03 / PASTE

Choose and paste

Press Enter or click to paste into your previous app. Hold Shift while choosing to copy only.

SETUP / FIRST LAUNCH

Setup

Windows

Extract the zip and run CPClipboard.exe. Keep uiohook.dll next to the executable. Pasting into an elevated app is unavailable; the snippet is copied instead.

macOS

Extract the zip and move CPClipboard.app to Applications. Allow CPClipboard in System Settings → Privacy & Security → Accessibility. Until permission is granted, selecting a snippet only copies it. For an unnotarized build, check its source before allowing it in Privacy & Security.

Add your snippets

Open Settings → Snippets from the tray or menu bar, choose a group, and select Add. Text edits are saved automatically.

Storage and clipboard

Snippets are stored on your computer. By default, your selected snippet stays on the clipboard after pasting for reuse with Ctrl+V / ⌘V. Restoring the previous clipboard is optional and off by default. Clipboard history, variables, macros and cloud sync are outside the app’s scope.
