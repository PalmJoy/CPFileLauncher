CPClipboard

いつもの文章を、すぐ貼り付け。

Windows・macOS向けの定型文ツール。Ctrlを2回押して、文章を選ぶだけ。ネオンの盤面から、元のアプリへ貼り付けます。

操作イメージ（画面の模型）

01 // Download

CPClipboard を入手

お使いのPCに合うzipをダウンロードし、展開して起動します。インストーラはありません。

公開版を確認しています。取得できない場合はGitHubのリリース一覧をご確認ください。

未公証のビルドです。初回の起動手順をご確認ください。はじめかたすべての配布ファイル・SHA256・来歴証明 ↗
02 // Workflow

使い方

01

Ctrlを2回で呼び出す

Alt / ⌥ + 中クリックでも開けます。トリガーは設定から変更できます。

02

10個のグループで整理

「編集…」で文章とグループ名を編集。数字キー0〜9でグループを切り替えます。

03

選んだら貼り付け

Enterまたはクリックで元のアプリへ貼り付け。Shiftを押して選ぶとコピーだけになります。

盤面の基本操作

盤面の基本操作
a–z / Shift+a–z上から26件を貼り付け / コピーだけ
↑ / ↓定型文を選ぶ
Enter / クリック貼り付け
Shift + Enter / Shift + クリックコピーだけ
0–9グループを切り替える
Esc盤面を閉じる
03 // Setup

はじめかた

  1. zipを展開する

    CPClipboardのフォルダ一式を同じ場所に置きます。uiohook.dllはCPClipboard.exeの隣に残してください。

  2. アプリを起動する

    CPClipboard.exeを開きます。トレイのメニューから設定を開けます。

  3. 盤面を呼び出す

    Ctrlを2回押して定型文を選びます。管理者として起動したアプリには貼り付けられず、コピーだけになります。

  1. Applicationsへ移す

    zipを展開し、CPClipboard.appをApplicationsフォルダへ移してから開きます。

  2. 初回の起動を許可する

    配布物は未公証です。信頼できる入手元を確認し、「システム設定 → プライバシーとセキュリティ」から起動を許可してください。

  3. アクセシビリティを許可する

    「システム設定 → プライバシーとセキュリティ → アクセシビリティ」でCPClipboardを許可します。未許可の間はコピーだけになります。

  4. 盤面を呼び出す

    Ctrlを2回押して定型文を選びます。

文章を登録する

トレイ／メニューバーのメニューから「編集…」を開き、グループを選んで「追加」。本文はその場で保存されます。

04 // Storage

保存とクリップボード

定型文はPC内に保存します。貼り付け後も選んだ定型文がクリップボードに残り、後からCtrl+V / ⌘Vで使えます。元のクリップボードへの復元は任意で、既定はOFFです。クリップボードの履歴・変数やマクロ・クラウド同期はありません。
