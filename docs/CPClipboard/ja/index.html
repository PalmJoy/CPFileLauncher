初回設定

Windows

zipを展開し、CPClipboard.exeを起動します。uiohook.dllはexeの隣に置いたままにしてください。管理者として起動したアプリには貼り付けられないため、コピーだけになります。

macOS

zipを展開し、CPClipboard.appをApplicationsへ移します。「システム設定 → プライバシーとセキュリティ → アクセシビリティ」でCPClipboardを許可します。未許可の間はコピーだけになります。未公証の配布物は、信頼できる入手元を確認したうえで「プライバシーとセキュリティ」から開いてください。

文章を登録する

トレイ／メニューバーのメニューから「設定… → 定型文」を開き、グループを選んで「追加」。本文はその場で保存されます。

保存とクリップボード

定型文はPC内に保存します。貼り付け後も選んだ定型文がクリップボードに残り、後からCtrl+V / ⌘Vで使えます。元のクリップボードへの復元は任意で、既定はOFFです。クリップボードの履歴・変数やマクロ・クラウド同期はありません。
