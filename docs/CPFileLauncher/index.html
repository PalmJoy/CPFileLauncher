02 // Features

A file launcher for everyday shortcuts

CPFileLauncher (CyberPunk FileLauncher) is a desktop file and app launcher that keeps your everyday shortcuts on a visual board. Organize work folders and websites into pages, and drag files and apps from Windows Explorer or macOS Finder to add them.

Ctrl+Alt+Space

Summon anywhere

Press Ctrl+Alt+Space (⌃⌥Space on Mac) or Ctrl(⌃)+middle-click. Triggers are configurable.

How to use the file launcher

How do I add files and folders?
Drag and drop them onto the board from Windows Explorer or macOS Finder. Group documents, work folders and apps into pages, then launch them from their icons.
How do I open my shortcuts quickly?
Summon the board with a hotkey or mouse trigger and select an icon. You can also drop a file onto an app icon to open it with that app.
Does it work on Windows and Mac?
It supports Windows 10 (1809 or later) and Windows 11 on x64 / ARM64, and macOS 15 or later on Apple silicon. Intel Macs are not supported. See the free downloads for each platform and first-launch instructions.

05 // Setup

First launch

CPFileLauncher is not code-signed by Apple or Microsoft yet, so your OS will warn you the first time. Here is how to open it.

  1. Extract the zip to any folder (it does not have to be Program Files).

    Keep the whole CPFileLauncher folder together — uiohook.dll must stay next to CPFileLauncher.exe, or hotkeys and mouse triggers will not work.

  2. Open CPFileLauncher.exe. If SmartScreen shows “Windows protected your PC”, click More info → Run anyway.

    To avoid the warning, right-click the zip → Properties → check Unblock before extracting.

  3. The icon appears in the notification area. Press Ctrl+Alt+Space to show the board.
  4. To start it automatically, turn on Start at login in Settings.

Known limitations

  • PCs with Smart App Control turned on cannot run unsigned apps, and there is no way around it.
  • Because the app uses a global keyboard and mouse hook, some antivirus software may flag it by mistake.
  1. Double-click the zip to extract it (Safari extracts it automatically).
  2. Move CPFileLauncher.app to the Applications folder first.

    Opening it from Downloads runs it from a temporary read-only location, and permissions will not stick after you move it.

  3. Open it. macOS says “CPFileLauncher” Not Opened — click Done.
  4. Open System Settings → Privacy & Security, scroll down and click Open Anyway, enter your password, then open the app again.

    Or run this in Terminal:

    xattr -dr com.apple.quarantine /Applications/CPFileLauncher.app
  5. Click the menu bar icon → Permissions… and allow Accessibility. ⌃⌥Space works once it is allowed.
  6. The first time a folder opens in a Finder tab, macOS asks to let CPFileLauncher control Finder — allow it.

Updating

Quit CPFileLauncher and replace it with the new version. Your items and settings are kept in the data folder.

macOS: permissions reset on every update

Because the app is not signed with an Apple Developer ID, macOS treats each version as a new app. After updating, repeat steps 3–4, remove the old CPFileLauncher from the Accessibility list with “−”, and allow it again (step 5).

Uninstalling

Turn off Start at login in Settings, quit the app and delete it. Then delete the data folder — %APPDATA%\CPFileLauncher\ on Windows, ~/Library/Application Support/CPFileLauncher/ on macOS. On macOS, also remove CPFileLauncher from Accessibility and Automation in Privacy & Security.

Troubleshooting

macOS says the app “is damaged and can’t be opened”.
Run the xattr command from step 4, then open it again.
The hotkey does nothing on macOS.
Remove CPFileLauncher from the Accessibility list with “−” and allow it again.
“You can’t open the application because it is not supported on this Mac.”
That Mac has an Intel processor. CPFileLauncher runs on Apple silicon only.
