02 // Features

よく使うものをまとめるファイルランチャー

CPFileLauncher（CyberPunk FileLauncher）は、よく使うファイルやアプリをアイコンで並べて起動するデスクトップランチャーです。作業用フォルダや Web サイトもページごとに整理でき、Windows では Explorer、macOS では Finder からドラッグ＆ドロップで登録できます。

Ctrl+Alt+Space

どこからでも呼び出す

Ctrl+Alt+Space（Mac は ⌃⌥Space）か Ctrl(⌃)+中クリック。呼び出し方は設定で変えられます。

ポップアップ
常駐

2 つの表示モード

カーソルの位置に出て起動したら消える「ポップアップ」と、デスクトップに置いておく「常駐」。

010203+

ドラッグ＆ドロップで登録

Explorer / Finder からファイル・フォルダ・アプリをドロップ。ページ（タブ）に分けて、ドラッグで移動・入れ替え。

→

ドロップで開く

ファイルをアプリのアイテムに落とすと、そのアプリで開きます。

DocumentsProjects

フォルダはタブで開く

フォルダは、いま開いている Explorer / Finder のウィンドウに新しいタブで開きます。

配色は 2 色、演出は HUD

主色と副色を選ぶだけ。出入りのグリッチ、走査線、ステータス行、常時の演出（任意）。

{ "pages": [ { "name": "Work", "items": [ … ] } ] }

データは読める形で

人が読める JSON に自動バックアップ付きで保存。エクスポート / インポートは zip 1 つ。

EN日本語

日本語と英語

画面はすべて日本語・英語の両方に対応しています。

ファイルランチャーの使い方

ファイルやフォルダを登録するには？
Explorer や Finder から盤面へドラッグ＆ドロップします。仕事の資料、作業フォルダ、アプリをページごとにまとめ、アイコンから起動できます。
登録したファイルをすばやく開くには？
ホットキーやマウス操作で盤面を呼び出し、アイコンを選びます。ファイルをアプリのアイコンへドロップして、そのアプリで開くこともできます。
Windows と Mac のどちらで使えますか？
Windows 10（1809 以降）・Windows 11 の x64 / ARM64 と、macOS 15 以降の Apple シリコン Mac に対応します。Intel Mac には対応していません。OS 別の無料ダウンロードと初回起動の手順をご覧ください。

05 // Setup

初回の起動

CPFileLauncher はまだ Apple / Microsoft のコード署名をしていないため、初回は OS が警告を出します。開き方は次のとおりです。

  1. zip を好きなフォルダに展開します（Program Files でなくてかまいません）。

    CPFileLauncher フォルダはまとめて置いてください。uiohook.dll が CPFileLauncher.exe の隣に無いと、ホットキーとマウスの呼び出しが動きません。

  2. CPFileLauncher.exe を開きます。SmartScreen の「Windows によって PC が保護されました」が出たら、詳細情報 → 実行。

    展開する前に zip を右クリック → プロパティ →「許可する」にチェックしておくと、この警告は出ません。

  3. 通知領域にアイコンが出ます。Ctrl+Alt+Space で盤面が出ます。
  4. 自動で起動したいときは、設定の「ログイン時に自動起動」をオンにします。

既知の制限

  • 「スマート アプリ コントロール」がオンの PC では、未署名のアプリは実行できず、回避する方法がありません。
  • キーボード・マウスのグローバルフックを使うため、ウイルス対策ソフトが誤って検出することがあります。
  1. zip をダブルクリックして展開します（Safari は自動で展開します）。
  2. 先に CPFileLauncher.app を「アプリケーション」フォルダへ移します。

    ダウンロードフォルダのまま開くと読み取り専用の仮の場所から動き、移した後に権限が合わなくなります。

  3. 開きます。「“CPFileLauncher”は開いていません」と出たら「完了」を押します。
  4. 「システム設定 → プライバシーとセキュリティ」の下の方にある「このまま開く」を押し、パスワードを入れて、もう一度アプリを開きます。

    またはターミナルで次を実行します。

    xattr -dr com.apple.quarantine /Applications/CPFileLauncher.app
  5. メニューバーのアイコン →「権限の設定…」から「アクセシビリティ」を許可します。許可すると ⌃⌥Space が効きます。
  6. はじめてフォルダを Finder のタブで開くとき、「Finder を制御」の確認が出るので許可します。

更新するとき

CPFileLauncher を終了し、新しい版に置き換えます。アイテムと設定はデータフォルダにあるので消えません。

macOS: 更新のたびに権限が外れます

Apple の Developer ID で署名していないため、macOS は版ごとに別のアプリとして扱います。更新したら手順 3〜4 をもう一度行い、アクセシビリティの一覧の古い CPFileLauncher を「−」で消してから、許可し直してください（手順 5）。

アンインストール

設定の「ログイン時に自動起動」をオフにしてからアプリを終了して削除し、データフォルダ（Windows は %APPDATA%\CPFileLauncher\、macOS は ~/Library/Application Support/CPFileLauncher/）も削除します。macOS では「プライバシーとセキュリティ」のアクセシビリティとオートメーションからも消してください。

困ったとき

macOS で「壊れているため開けません」と出る
手順 4 の xattr のコマンドを実行してから、もう一度開いてください。
macOS でホットキーが効かない
アクセシビリティの一覧から CPFileLauncher を「−」で消し、許可し直してください。
「このアプリケーションはこの Mac では使用できません」と出る
Intel の Mac です。CPFileLauncher は Apple シリコン専用です。
